# Лицензии публичной поставки M53-Colpo

Собственный код приложения распространяется по [AGPL-3.0-only](../../LICENSE). Для каждого выпуска доступны его исходники и архив оригинальных зависимостей из обоих Cargo.lock. Версии и SHA-256 этих архивов проверяются при подготовке поставки.

## Состав поставки

| Компонент | Лицензия и уведомления |
| --- | --- |
| Код клиента, сервера, интерфейса и установщиков | AGPL-3.0-only. Текст лицензии входит в репозиторий и пакеты. |
| Rust-зависимости | Действуют лицензии, объявленные в исходных публикациях. Реестры Windows, Linux и сервера указывают версию, лицензию, исходники и уведомления для каждого компонента. |
| Вложенная копия GPUI Windows 0.3.9 | Apache-2.0. Сохраняются текст лицензии и указания на изменённые файлы. |
| DejaVu Sans | Условия Bitstream Vera и уведомления о шрифте включены в Windows и Linux. Запись GPL в Debian-уведомлении относится к файлам пакета Debian. |
| Chromium Headless и PDF.js для Windows | Установщик получает готовые архивы из официальных источников и проверяет SHA-256. Уведомления поставщиков сохраняются в установленных компонентах печати. |
| Системные компоненты | Linux использует библиотеки своего дистрибутива. Compose загружает Debian и PostgreSQL из официального реестра. Windows при необходимости использует Visual C++ Redistributable от Microsoft. |

Если исходная публикация допускает выбор лицензии, для `self_cell` и `r-efi` в этой поставке используется разрешённый вариант Apache-2.0. Исходные декларации и тексты лицензий сохранены. Пакет `option-ext` сохраняет MPL-2.0, а данные `webpki-roots` сохраняют CDLA-Permissive-2.0.

## Архив уведомлений

Файл `Colposcopy-License-Notices.zip` на странице выпуска содержит три реестра установочных пакетов, перечень исходников Cargo, тексты SPDX и дополнительные уведомления из исходных публикаций. Для точных ссылок и проверочных сумм смотрите файлы `SOURCES.tsv` внутри архива. Сохраняйте архив уведомлений и соответствующие исходники вместе с распространяемыми бинарниками.

Конвейер выпуска собирает уведомления из используемых зависимостей. Если версия не содержит отдельного текста лицензии, он сохраняет её опубликованную декларацию и атрибуцию и добавляет полный текст из проверенного каталога. Неизвестная лицензия требует проверки до упаковки. При добавлении ресурса или библиотеки укажите источник и условия его распространения.
