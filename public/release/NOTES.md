# Предварительный выпуск M53-Colpo

Кольпоскопия без МИС и 1С. Клиент работает с собственным сервером организации. В комплекте есть установочные файлы для x86-64 и контрольные суммы.

- **Windows 10/11 x64** — распакуйте `Colposcopy-Windows-x64.zip`. Запустите `Setup.ps1`. При первом запуске установщик проверит и скачает официальные компоненты печати.
- **Debian 12 и Ubuntu 24.04 x64** — установите `Colposcopy-Linux-x64.deb` через `sudo apt install ./Colposcopy-Linux-x64.deb`. В Linux доступен импорт снимков, PDF и печать через CUPS. Прямой захват с камеры предусмотрен в Windows-клиенте.
- **Сервер Linux x64** — распакуйте `Colposcopy-Server-Linux-x64.tar.gz` и запустите готовый серверный бинарник в Docker Compose по руководству администратора. Компиляция на сервере не требуется.
- **Исходники** — `Colposcopy-Source.zip` и `Colposcopy-DependencySources.tar.gz`. Собственный код выпускается под AGPL-3.0-only. Архив «Colposcopy-License-Notices.zip» содержит тексты лицензий и реестры компонентов.

Для проверки первого запуска используйте синтетические данные. Клиент подключается по HTTPS к вашему серверу. Перед клиническим применением проверьте требования своей юрисдикции, локальные правила работы с медицинскими данными и допуск применяемых справочников.
